**Prepared; no human acceptance run is recorded here.** The latest automated baseline is in [the operations handoff](P9_OPERATIONS_HANDOFF.md). Use fictional records only; no animal handling, private household data or real-world outcome is part of these tasks. ## Set up and record the actual environment

Use the running local app and its [runtime instructions](P9_HARDENING_HANDOFF.md#final-checkpoint-and-local-continuation). Leave providers disabled for the text-only pass. A human records the date, device/OS, browser/version, input method, screen reader/version, native browser zoom and viewport. Use an anonymous participant reference; keep personal details, account tokens, one-time deletion codes and raw captures private. A person who only watches a recording has not completed an interactive task. One person switching two caregiver roles must be labeled a one-person role simulation.

Each task starts `NOT_RUN`. Record `PASS`, `FAIL` or `BLOCKED` only after observing it, with the expected behavior, actual focus/spoken feedback, any assistance and the exact software revision. Do not turn assistance into an unassisted pass. Retest an issue after its fix; preserve the failed result. Unknown or inaccessible states fail closed.
