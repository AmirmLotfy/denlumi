Same home.

FROM REPORT TO HANDOVER

The context survives
the conversation.

A report is a report. An unknown stays unknown. The software never claims to supervise or physically separate animals.

  1. 01

    Start with the right household.

    Cat–cat, dog–dog and both cat–dog newcomer contexts have distinct fictional fixtures. Single-pet care needs no invented second pet.

  2. 02

    Review the exact update.

    Owner review, caregiver handover and session preflight check the current revision and safety epoch against database state.

  3. 03

    Preserve what was actually reported.

    Actor, target, negation, uncertainty, observation time and report time remain separate. A human confirms the exact draft.

  4. 04

    Pause the software. Keep the record.

    Confirmed concerns invalidate old guidance. Local Stop works without the network; a private factual preview stays under the owner's control.

CLEAR ABOUT THE BOUNDARIES

Built locally. Disclosed honestly.

Implemented in the local application
Authenticated shared state, real Streamable HTTP MCP, stale-plan refusal, explicit handovers, fictional pairing flows, private record previews and network-free local Stop.
Historical provider evidence
Polly and Transcribe app requests passed. Bedrock inference remains blocked in the recorded checks. Human microphone capture and audible playback acceptance are still open.
Before practical use
Qualified review of each exact content version, human usability and accessibility checks, operating arrangements and hosted backend authorization are still required. No native Alexa connection or certification is claimed.
